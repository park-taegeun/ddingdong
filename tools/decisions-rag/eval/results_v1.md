## ⑨ 사전 등록과 달라진 점

- (a) 채점 절차 — 사전 등록은 「사용자 블라인드 채점」. 실제: 기준선 = Claude 1차 25행 + 사용자 직접 5행 · 사용자 확인(2026-10-07 12:43) / 2라운드 = Claude 1차 판정(조건 이름 없는 블라인드 시트) → 판단이 갈릴 수 있는 5행을 사용자에게 제시 → 사용자가 전문가 판단 제안을 요청 → 권고(1행 정답 → 부분) 수용 = 사용자 결정(권고 수용) 2026-10-07 13:37. 기준 = PREREG 판정 기준 + 기준선 때와 같은 판정 규칙 4개(메모 칸 머리 「규칙1~4」).
- (b) 호출 실패 규칙 — 시트를 보기 전에 선언: 로컬 모델 호출 실패로 답이 빈 행 = 오답으로 채점하고 「호출 실패」를 따로 적는다. 해당 1행(exaone · Q12).
- (c) RRF 목록 깊이 50 — 사전 등록에 없던 값. 결과 전 커밋 02b80a6에서 고정.
- (d) 형식 오류(모델 출력이 JSON이 아님)를 거절로 세지 않는다 — 원문을 답으로 남긴다. 이번 실행 해당 0행.
- (e) 로컬 모델 비교(⑥)는 사전 등록 밖이다.
- (f) 환각 정의에서 호출 실패 행을 뺐다(모델이 지어낸 답이 아님). 이번 결과에서 해당 0행 — 호출 실패 1행이 not_in_doc이 아니어서 환각 수는 바뀌지 않았다.
