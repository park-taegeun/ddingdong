## 적중 정의

답이 있는 문항(25)은 「정답 조각(`gold_anchors`) 중 하나의 전체 문자열을 담은 청크」가 상위 k 안에 있으면 적중(`gold_match` = `any`). 청크 텍스트 = 표시 원문(마스킹 반영). not_in_doc(5)은 검색 지표에서 뺀다(n 표기).

## 지표

- 검색 = Hit@3 · MRR@10(전체 · 유형별, 문항 수로 — 「n = 25 중 m」 형식 병기)
- 답 = 사용자 블라인드 3단계 채점(정답 / 부분 / 오답 — 뜻 단어로 입력). 유형별 기준:
  - fact · identifier · reversal = 기대 답의 핵심 값 · 상태가 맞으면 정답 / 일부만 맞으면 부분 / 틀리거나 폐기안을 답이면 오답
  - not_in_doc = 「문서에 없다」를 밝히면 정답, 지어내면 오답
  - false_premise = 전제를 바로잡으면 정답, 전제를 받아들이면 오답
- 쌍 지표 = 환각(not_in_doc에서 거절하지 않고 오답) ↔ 과잉 거절(답이 있는 문항에서 refused = true) — 둘을 항상 같이 보고
- 근거 유효(자동) = 답한 문항 중 인용 청크 하나 이상이 정답 조각을 담은 비율
- 번복 오답(자동 보조 + 채점) = reversal 답이 폐기안(`trap_anchors` 쪽 값)을 택한 수
- 지연(검색 · 답변 초) · 비용(토큰 · 달러)

## 대조군

- random = 시드 고정 무작위 상위 k(기대치 ≈ 0 — 청크 1,331개 중 정답 청크 1~4개)
- bm25 = 토크나이저 = 소문자 영숫자 단어(`[a-z0-9_]+`) + 한글 연속 구간의 음절 2-gram(한 음절 구간은 그 음절 하나) · 계수 k1 = 1.5 · b = 0.75. 문서 = 청크의 임베딩 본문(제목 경로 줄 + 본문)과 같은 텍스트
- gold_removed = 문항마다 그 문항의 정답 조각을 담은 청크를 뺀 인덱스로 검색 → 그 문항 Hit@3가 반드시 0(아니면 평가기 결함 — 실행 실패로 처리)

## 실험

각각 기준선 대비 한 변수 · 오답 분석 뒤 실행.

- E1 = `mark_superseded` 참(취소선 → [폐기] 표시). 채택 = reversal 정답 수 +1 이상 · 나머지 25문항 정답 수 감소 0 · 전체 Hit@3 감소 0

- 표본이 30이다 — 결과는 방향 판단용이며 일반화 주장을 하지 않는다.
